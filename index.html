Screen 01 — Basic Information
The Hook · Mobile-first lead capture
Design Principle
Large, tap-friendly fields. Avoid clutter. Prioritise mobile-first rendering. Progress bar visible at top across all 4 screens.
Fields & Interactions
FIELDLoan Purpose — Horizontal visual cards, tap to select one.
FIELDFull Name — Text input; label "as per PAN card".
FIELDMobile Number — Numeric keyboard; +91 prefix locked.
FIELDAnnual Income — Numeric keyboard; inline hint ₹8,00,000.
FIELDRequired Loan Amount — Numeric keyboard; inline hint.
FIELDPIN Code — 6-digit numeric; auto-validates location viability on entry.
UX & Logic Notes
UXMin tap target 44×44 px on all interactive elements.
UXInline validation — errors surface below the field immediately, not on submit.
LOGICCTA "Check My Eligibility »" disabled until all fields pass validation.
LOGICPIN code triggers a serviceability check; show inline error if location is unserviceable.
DROP-OFFIf user abandons after this screen, data is NOT saved (no PAN/CIBIL yet).

Screen 02 — CIBIL & Verification
The Gateway · Trust-critical screen
Design Principle
This screen must appear highly secure and trustworthy to reduce drop-off. Show security badges prominently. Reassurance copy is critical.
Fields & Interactions
FIELDPAN Number — Auto-capitalise; regex AAAAA1111A. Validate on blur.
UXSoft-inquiry note displayed prominently before OTP entry.
FIELDOTP — 6-digit blocks sent to mobile from Screen 1. Numeric keyboard.
LOGICOTP timer: 60-second countdown. "Resend OTP" appears after countdown expires.
CONSENTMandatory checkbox — CTA is locked until checked.
Logic & Drop-Off Handling
DROP-OFFIf user drops off on Screen 2, Screen 1 data must be saved as a "Dropped Lead" for tele-calling follow-up.
APIOTP delivery blocks progress — modal appears immediately after PAN entry. Blocks to verified.
SESSIONSession token expires after 30 minutes of inactivity.

Screen 04 — Thank You
Setting Expectations · End of journey
Design Principle
Clean, clutter-free, and reassuring. Triggered after user clicks "Proceed to Lock In Offer" from Screen 3 popup. No further input required.
Visual Elements
ICONLarge animated green checkmark or house-with-key illustration.
COPYCore message confirms submission and sets 2-working-day callback expectation.
FRAUDFraud prevention block is mandatory — states corporate number series starting with 140 and warns against sharing OTPs.
Technical Notes
LEADFull lead record (Screens 1–3 data) committed to CRM/database on reaching this screen.
SESSIONSession cleared after Thank You screen renders. No back navigation allowed.
A11YMinimum tap target 44×44 px. Screen reader accessible with ARIA labels on all interactive elements.
